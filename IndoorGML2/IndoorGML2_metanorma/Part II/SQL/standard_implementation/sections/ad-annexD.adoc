== Navigation code list types

The following PostgreSQL `ENUM` types represent IndoorGML navigation code lists:

* `LocomotionAccessType` for the `NavigableSpace.locomotionType` column;
* `GeneralSpaceFunctionType` for the `GeneralSpace.function` column;
* `TransferSpaceFunctionType` for the `TransferSpace.function` column;
* `TransferSpaceCategoryType` for the `TransferSpace.category` column;
* `NavigableBoundaryFunctionType` for the `NavigableBoundary.NavigableBoundaryFunction` column.

NOTE: <<annex-e>> lists OmniClass example codes for space function and category values.
Those codes are not `ENUM` labels of the types in this annex.
