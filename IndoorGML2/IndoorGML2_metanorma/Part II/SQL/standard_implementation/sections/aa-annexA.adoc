identifier:: /conf/core/cellspace
target:: /req/core/cellspace
test-purpose:: For the following columns of the `CellSpace` table, verify that:
+
--
* The `PoI` column declares whether it is a point of interest space. +
* The `duality` column references the `NodeID` of the corresponding `Node`. +
* Every non-null `cellSpaceGeom_Geometry2D` value has the geometry type `POLYGON` or `MULTIPOLYGON`. +
* Every non-null `cellSpaceGeom_Geometry3D` value has the geometry type `POLYHEDRALSURFACE` or `TIN`. +
* Every non-null `cellSpaceGeom_Geometry3D` value has three coordinate dimensions and satisfies `CG_IsSolid(CG_MakeSolid(...))`.
--
test-method:: Inspect the database schema and instance data to verify the above requirement.

[abstract_test]
====
[%metadata]
identifier:: /conf/core/interlayerconnection
target:: /req/core/interlayerconnection
test-purpose:: For the following columns of the `InterLayerConnection` table, verify that:
+
--
* The `connectedLayers_1` and `connectedLayers_2` columns reference the two connected `ThematicLayer` rows. +
* The `typeOfTopoExpression` column stores the topological relationship, with subject on the `_1` side. +
* The `typeOfTopoExpression` value is one of "Contains", "Overlaps", "Equals", "Within", "Crosses", or "Other". +
* The paired `connectedLayers_*`, `connectedNodes_*`, and `connectedCells_*` columns are ordered and mapped to the same indices. +
* When connected nodes are provided, both `connectedNodes_1` and `connectedNodes_2` are populated. +
* When connected cell spaces are provided, both `connectedCells_1` and `connectedCells_2` are populated.
--
test-method:: Inspect the database schema and instance data to verify the above requirement.
====
